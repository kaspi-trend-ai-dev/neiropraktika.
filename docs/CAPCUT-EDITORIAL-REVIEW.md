# Редакционная проверка первого мастер-класса CapCut

**Текущая версия:** `drafts/capcut-subtitles-reels.json` — ещё НЕ опубликована.

## Вывод

Инструкция о создании и редактировании автоматических субтитров соответствует официальной документации CapCut на уровне описанных возможностей. Проведена сверка первоисточника и текстовый разбор содержания; **реальный монтаж видео в CapCut не проводился**. Автоматический аудит `reports/fact-check.json` дал `candidate_for_human_review`, но этот статус не заменяет личное прочтение перед выпуском.

## Проверенные функции

- Автогенерация субтитров из аудио: официальный документ CapCut указывает **Auto Captions / Recognise Subtitles**.
- Web: **Captions → Auto Captions → Recognise**, далее выбор языка и генерация.
- Desktop: **Captions → Auto Captions**, источник звука, язык, затем **Generate**.
- Mobile: **Captions → Auto Captions**, выбор языка и генерация.
- Текст, длительность и оформление субтитров доступны для ручной правки; дополнительные функции могут зависеть от платформы и региона.
- CapCut рекомендует проверять и корректировать автоматическое распознавание вручную.

**Официальный первоисточник:** https://www.capcut.com/help/how-to-recognise-subtitles

Дополнительная справка об исправлении ошибок: https://www.capcut.com/help/auto-captions-in-capcut

## Практическая проверка содержания

- Восемь пошаговых действий ведут к ясному результату — видео с субтитрами.
- Рабочий пример показывает **вымышленную** фразу о деревянном органайзере, типичные ошибки распознавания и исправленный текст.
- В тексте нет утверждений о реальных охватах, заказах, продажах или уже проведённом измерении.
- Четыре промпта помогают разделить субтитры, проверить ошибки, улучшить орфографию без изменения смысла и проверить визуальную читаемость.
- Указаны ограничения интерфейсов по устройствам и необходимость ручной проверки.
- Примерные таймкоды учебного фрагмента нельзя воспринимать как точное измерение реального видео.
